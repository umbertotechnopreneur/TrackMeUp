# App design options

Six ways to give these parts of TrackMeUp a consistent look:

- Main window
- Screenshot scheduler
- Screenshot gallery and inspector
- Settings inside the current window

All options follow World clocks: translucent Windows surfaces, clear typography,
coral highlights, and familiar controls. Settings stay in the current window.
These are design explorations, not screenshots of the shipped app. Some images
retain Italian interface labels from the original design session.

## Original generation prompt

Create a high-fidelity, shippable Windows 11 WinUI 3 design board for TrackMeUp. Show the Main window, Screenshot Scheduler, Screenshot Gallery, and the in-window Options layer as one coherent product family. Preserve the functional controls and Italian labels. Reuse the World Clocks visual language: genuine Acrylic/Mica, 48 px integrated title bars with the TrackMeUp PNG mark, Segoe UI Variable, coral and violet semantic accents, thin dividers, large light numerals, and careful optical alignment. Avoid card walls, opaque full-window veils, colored icon tiles, popup settings, custom message boxes, carousels, neon, and decorative blur.

Each image then applies the variant-specific idea described in the table above.
