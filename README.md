# TrackMeUp

TrackMeUp is a Windows WinUI 3 utility application.

## Purpose

This repository contains the `TrackMeUp` application source and a shared `scripts` folder for repository utilities.

## Layout

- `TrackMeUp/` — WinUI 3 app and project files.
- `scripts/` — copied utility scripts from the local template.
- `.github/` — copilot instructions, prompts, and task notes.
- `AGENTS.md` — operating instructions for contributors and agents.

## Quick start

```powershell
dotnet restore .\TrackMeUp\TrackMeUp.csproj
dotnet build .\TrackMeUp\TrackMeUp.csproj -p:Platform=x64
```
