# PawnIO official installer

TrackMeUp x64 includes the unmodified, digitally signed PawnIO 2.2.0 installer
from https://github.com/namazso/PawnIO.Setup/releases/tag/2.2.0 . Its download
and SHA-256 are pinned in `distribution.json`.

Copyright namazso. The official binary distribution is proprietary; the author
explicitly permits redistribution of the installer:
https://github.com/namazso/PawnIO.Modules/wiki/Using-PawnIO-Modules#licensing-considerations .
The separately published driver source has GPL terms and an IOCTL exception:
https://github.com/namazso/PawnIO#license . These are separate from TrackMeUp's MIT license.

Installation uses the official signed edition and requires Windows administrator
consent. No unrestricted driver is selected. PawnIO is a shared system component;
removing TrackMeUp does not remove PawnIO or affect other applications using it.
