# Changelog

All notable TrackMeUp changes will be documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and tagged releases will follow [Semantic Versioning](https://semver.org/) once
the first public preview establishes the compatibility baseline.

## [Unreleased]

### Added

- Concise SPDX MIT headers and automated source-header verification.
- First-party AI asset provenance and explicit separation from third-party media.
- Structured bug, feature, and documentation issue forms plus a pull-request template.
- Public roadmap and architecture overview for contributors.
- Dependabot coverage for NuGet, npm, and GitHub Actions dependencies.

### Changed

- Privacy messaging now presents the built-in clean-slate action in product language.

### Security

- Repository automation continues to use least-privilege workflow permissions and commit-pinned actions.

Release history will begin with the first tagged public preview.
