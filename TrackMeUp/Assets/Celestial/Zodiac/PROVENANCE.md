# Zodiac interface artwork

Created on 2026-09-19 with the built-in ImageGen tool at the project owner's request. Twelve independent text-to-image calls produced the twelve traditional zodiac glyphs. These are decorative AI-generated interface illustrations, not astronomical observations, constellation diagrams or astrological predictions. The application separately identifies the current tropical 30-degree sector using its shared astronomical model.

All twelve original PNG outputs were copied into this directory without local pixel edits, recoloring, resizing or alpha extraction. The requested size was 512 × 512; the built-in tool returned 1254 × 1254 for each asset. Visual inspection confirmed the intended glyphs and consistent warm-gold style. Alpha inspection on an 8-pixel sampling grid confirmed fully transparent background pixels and nonzero, near-opaque glyph pixels in every file; semitransparent generated edge/glow pixels are preserved. The assets have no baked checkerboard or background plate.

Licensing follows the project's asset policy in ASSET_LICENSING.md. This provenance record does not change existing artwork rights. No external reference image, photograph, logo or third-party font asset was supplied to these generations.
