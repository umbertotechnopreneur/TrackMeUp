# Store screenshots

Approved Microsoft Store screenshots will live in this directory.

Before adding one, remove personal data, private URLs, API keys, customer information, and anything that could reveal another person's work. Use stable demo data and keep the image filename descriptive, for example:

- `en-US-01-timeline.png`
- `en-US-02-reports.png`
- `it-IT-01-timeline.png`

Update [`../listing.json`](../listing.json) at the same time with the locale, caption, and purpose for every screenshot.
