# TrackMeUp icon provenance

This record accompanies `trackmeup-icon-reference.png` and the application
identity assets generated from it under `TrackMeUp/Assets/`.

Repository history first records the reference image in commit `0f7ce7d` on
2026-08-05 (`feat: establish initial TrackMeUp application baseline`). The
repository script `scripts/TrackMeUp.ps1` uses that reference to generate the
TrackMeUp app icon, Store logo, square and wide logos, and splash-screen
variants.

On 2026-08-30, project owner Umberto Giacobbi confirmed that the reference was
created with an AI-assisted image-generation workflow run on a system under his
control. The exact historical model, version, and prompt were not retained. He
selected and reviewed the reference and authorized the reference and its
generated derivatives for publication in the public TrackMeUp source
repository and official TrackMeUp binaries. The repository-wide declaration is
recorded in [`AI_ASSET_PROVENANCE.md`](AI_ASSET_PROVENANCE.md).

For repository license-scope purposes, the reference and its identity
derivatives are treated as TrackMeUp Brand Assets governed by the
[Trademark and Brand Policy](../../TRADEMARKS.md), not by the MIT License.
Forks and independent distributions must replace the TrackMeUp identity assets
unless separate permission has been granted. See the repository-wide
[asset licensing record](../../ASSET_LICENSING.md). This record is not legal
advice.
