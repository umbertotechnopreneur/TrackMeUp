# Recall Timeline banner

This is the selected WorkTrail illustrative direction. It is promotional artwork, not an app screenshot or UI depiction.

The composition reads from left to right: older visual memories begin blurred and translucent, then folders, pictures, documents, and web pages become progressively sharper. The retrieval point lifts one older page out of the timeline to communicate that WorkTrail helps you find a half-remembered moment from days earlier.

## Final assets

All files under `output/` are PNG assets. `manifest.json` records their dimensions, PNG header values, and SHA-256 checksums.

- `worktrail-social-preview-github-1280x640.png`: 2:1 GitHub repository social preview. It is a size-only 1280 x 640 derivative of approved ImageGen art, with no text or compositing; it is not a screenshot.
- `*-master-3840x1280.png`: large 3:1 master artwork.
- `*-readme-2400x800.png`: 3:1 README-banner derivatives.
- `*-mark-*-1024x1024.png`: square symbol crops.
- `worktrail-recall-timeline-theme-pair-preview-2400x1600.png`: stacked comparison preview. The filename is a retained legacy input name.

No standalone text-wordmark output is retained or generated by this directory.

The `source/` images preserve the selected historical generated artwork. `render_assets.py` performs deterministic center cropping, restrained enlargement sharpening, art-only themed exports, sRGB embedding for generated files, and RGBA validation. It does not create a wordmark.

## Legacy banner inputs

The `worktrail-recall-timeline-banner-*` filenames remain active app build inputs. This bounded cleanup intentionally leaves those files and paths in place; rename or replace them only together with their configuration consumers. The root README does not currently consume this Recall Timeline direction.

## GitHub social preview

Upload `output/worktrail-social-preview-github-1280x640.png` in the repository's **Settings → General → Social preview** section. This is a repository setting; the README cannot select the social preview image itself.

## Rebuild

From the repository root on Windows:

```powershell
pwsh -NoProfile -Command 'python .\design\branding\recall-timeline\render_assets.py'
```

The renderer uses Pillow. It fails fast if the source images or the separately supplied WorkTrail social preview are unavailable.
